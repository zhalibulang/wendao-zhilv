# 问道之旅 v29 · AI 深度优化版

北京导游资格考试游戏化复习应用（PWA）。本版在 v28 基线上完成 AI 链路系统性优化（详见《检测报告》与《开发规划》R1–R4），全部改动本地生效，未运行测试、未推送 GitHub。

## 打开方式

双击 **`index.html`** 即可运行（Safari / Chrome / Edge，无需服务器）。线上部署后手机可"添加到主屏幕"安装为 PWA；`file://` 打开时 PWA 特性自动降级，游戏功能不受影响。

## AI 功能配置

1. 进入 **存档** 页签 → DeepSeek 智能引擎 → 粘贴密钥（sk-…）→ 保存（会做连通测试）。
2. 密钥仅存本浏览器独立存储，**不再随存档导出**；未配置/离线时自动使用内置话术，不影响修行。
3. 对话页顶部有 AI 状态点：绿=正常、黄=临时异常（自动重试/降级）、红=密钥或额度问题、灰=未配置。
4. **实验特性**（配置中心 → 实验特性）：对话导演 / 工具调用 / 主动传音，可独立开关。

## 修改指引

- 改 NPC 名字/称号/人设/分幕话题/降级台词 → `npc-registry.js` 对应 NPC 对象
- 改世界观默认文本 → `wd-chat.js` 的 `worldBrief()`（用户自定义仍走配置中心）
- 改 AI 行为约束 → `wd-chat.js` 的 `defaultAiDocument()`（用户 AI 文档仍可完全覆写）
- 改 API 参数档位 → `index.html` 的 `DS_PROFILES`
- 改废弃术语黑名单 → `npc-registry.js` 的 `WD_OBSOLETE_TERMS`（全站唯一来源）
- 改降级话术 → `wd-chat.js` 的 `fallback()`（开口/剧情池与注册表 fallbackOf 同源）

## 验证（部署前建议）

1. 双击 `index.html` → 序章正常 → 进入主界面无控制台报错（npc-registry 校验警告需处理）。
2. 配置密钥后发一条消息：应看到逐字上屏（流式生效）、状态点绿色。
3. 断网/输错密钥再发消息：降级话术（不再有「我记下了」句式）、状态点变色。
4. `@所有人`：各 NPC 回复应有互相接话（对话导演生效）。
5. 完整回归：进入任务/试炼/巡夜/藏经阁/集市各页无报错。
