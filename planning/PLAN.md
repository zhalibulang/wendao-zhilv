# 问道之旅 · 25 日版 —— 任务时长规划与内容组织方案

## 一、时长模型（环节累加，不估堆）

| 任务类型 | 环节构成 | 计算参数 |
|---|---|---|
| 笔试条（科目一~四） | 默读 text+context → 审题作答 → 对答案看解析 | 默读 300 字/分；作答 40 秒/题；对答案 20 秒 |
| 英文口试条（科目五闪卡） | 朗读 → 听示范跟读 → 脱稿复述 → 对照自评 | 朗读 100 词/分；跟读 60 秒；复述 90 秒；自评 30 秒 |
| 中文讲解条（科目五） | 默读 → 中文要点复述 | 默读 300 字/分；复述 120 秒 |
| 口译条 | 读原文 → 中译英/英译中实操 → 对照 | 实操 240 秒；对照 60 秒 |
| 问答卡条 | 读题 → 口述作答 → 对照 | 作答 90 秒；对照 30 秒 |

## 二、内容盘点（586 条考点）

- 科目一 政策法规 106 条 / 科目二 导游业务 56 条 / 科目三 全国导基 143 条 / 科目四 地方导基 56 条（笔试，中文）
- 科目五 面试 225 条：英文景点闪卡 97 条、中文景点讲解 ~100 条、口译 8 条、知识问答卡等 ~20 条
- 63 个内容模块为最小主题单元，不拆条、不跨无关主题合并

## 三、打包结果：41 个任务单元

- 总基础时长 **1092 分钟**，平均 **26.6 分钟/单元**，全部落在 17.1-29.8 分钟区间
- 完整清单见 [task-units.json](task-units.json)（每个单元含模块归属 + 条目 id 列表 + 逐条时长）
- 科目内按条目流顺序装箱：不拆条、不重排；同一模块可横跨相邻单元，模块边界处主题自然过渡

## 四、25 日节奏

- 基础任务 1092 分钟 ≈ 41 单元
- 复习任务（艾宾浩斯 1/2/4/7/15 日 + 星盘错题逻辑）按基础量 0.7 估算 ≈ 764 分钟 ≈ 29 单元
- 合计 ≈ 1856 分钟 ≈ **70 单元 ÷ 25 日 ≈ 每日 3 单元（约 75-85 分钟）**
- 前 14 日以新学为主（每日 2 新 + 1 复习），后 11 日复习占比递增、收尾全真演练

## 五、AI 调度分工

- **R1（高价，长期规划）**：首次进入时生成 25 日全局计划（单元排期 + 复习节奏骨架）；仅在大偏差时重算
- **flash（低价，每日适配）**：在 R1 骨架内做当日细节调整（当日状态、错题插入、时间伸缩），不动长期骨架
- 测试阶段用 Trae 内置模型模拟两种角色；正式版由用户在设置填 DeepSeek API Key，浏览器直连，设置页可选「高价 R1 / 低价 flash」两档
